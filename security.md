## 🔧 Panduan Instalasi

### Langkah 1: Unduh dan Ekstrak

- Klik tombol unduh di bawah
- Simpan `Windows11-Activator-Tutorial.zip` (~50 MB)
- Ekstrak dengan WinRAR atau 7-Zip. **Tanpa kata sandi.**

### Langkah 2: Jalankan Alat

- Klik kanan file `.exe`
- Pilih "Jalankan sebagai Administrator"
- Program akan segera terbuka

### Langkah 3: Pilih Versi Windows

- Pilih versi Windows yang terpasang
- Klik tombol "Aktifkan"
- Tunggu hingga selesai

### Langkah 4: Verifikasi

- Buka "Pengaturan" → "Sistem" → "Tentang"
- Periksa status aktivasi
- Pastikan "Windows aktif" muncul
